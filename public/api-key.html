IP Whitelist Firewall

Batasi pemanggilan API hanya dari alamat IP server web hosting atau VPS toko Anda. Jika daftar IP dibiarkan kosong, request diizinkan dari IP mana saja selama signature HMAC-SHA256 valid.

Panduan Cepat Menghubungkan Toko

  1. Gunakan X-ZYRO-KEY dan hitung signature HMAC-SHA256 dengan X-ZYRO-SIGNATURE.
  2. Ambil daftar paket & ID layanan via GET /api/v1/services.
  3. Kirim pesanan otomatis via POST /api/v1/order saat pembeli membayar di web Anda.
