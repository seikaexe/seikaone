Panduan Langkah Deploy Bot WhatsApp

1
Buka Menu "Buat Server Panel"

Pilih node server yang sesuai dengan hak role Anda (Legal Publik, Private, Enterprise, atau Ilegal). Tentukan nama server serta kapasitas RAM & CPU.

2
Login ke Pterodactyl

Klik link domain Pterodactyl yang diberikan. Masukkan username & password panel Anda yang telah dibuat saat deploy akun.

3
Upload Script Bot (ZIP)

Buka tab File Manager di panel. Upload file script bot dalam bentuk ZIP. Setelah selesai, klik titik tiga lalu pilih Unarchive.

4
Start Server & Scan Pairing Code

Masuk ke tab Console lalu klik tombol Start. Tunggu proses instalasi modul (npm install) hingga kode pairing atau QR Code WhatsApp muncul. Sambungkan WhatsApp bot Anda!

Tips Optimasi Bot Anti Delay & Anti Crash:
  • Gunakan RAM minimal 2GB - 4GB untuk bot grup aktif agar tidak terjadi restart mendadak (Out of Memory).
  • Jika bot digunakan untuk transaksi cepat atau sewa bot premium, disarankan menggunakan node Legal Private (Bandung) atau Enterprise yang memiliki konektivitas latency super rendah.
  • Hindari script bot dengan loop berkepanjangan tanpa jeda delay (bisa memicu CPU spike 100%).
