SeikaOne API

REST API untuk integrasi otomatis pembuatan panel Pterodactyl, kode klaim role, dan server cloud. Semua endpoint mengembalikan JSON dengan field status (boolean) dan data terenkripsi.

Base URL: https://zyrostore.id/api/v1
Format: application/json
HTTPS only

Autentikasi & Syarat Integrasi

Public API Authentication Protocol

Semua endpoint /api/v1/* merupakan Public API terproteksi (wajib API Key + IP Whitelist). Server memvalidasi kredensial pada setiap request untuk mengamankan saldo akun Anda dari akses tidak sah.

1
Buat API Key Masuk ke menu Kelola API Key → klik tombol Buat API Key Baru. API Secret hanya ditampilkan sekali saat dibuat — simpan baik-baik karena tidak dapat dilihat ulang demi keamanan.
2
Daftarkan IP Whitelist (Sangat Direkomendasikan) Di halaman Kelola API Key, bagian IP Whitelist, tambahkan IP server atau IP hosting bot Anda. Jika diisi, request dari IP lain otomatis ditolak (HTTP 403) untuk mencegah kebocoran saldo.
3
Kirimkan Kredensial via HTTP Header Kirimkan API Key melalui header request di bawah ini (pilih salah satu format):
HEADER (DIREKOMENDASIKAN)
X-Zyro-Key: zyro_live_xxx
BEARER TOKEN (ALTERNATIF)
Authorization: Bearer zyro_live_xxx
Penting: Request API wajib memenuhi syarat autentikasi: API Key valid & aktif, dan IP pengirim terdaftar di IP Whitelist (jika fitur whitelist diisi pada profil mitra).
4
HMAC-SHA256 Signature dengan API Secret (Wajib untuk POST) Setiap request yang mengubah data / memotong saldo (seperti POST /api/v1/order dan POST /api/v1/status) wajib ditandatangani menggunakan API Secret Anda untuk menjamin keaslian payload.
Rumus Pembentukan String to Sign:
String_To_Sign = TIMESTAMP + "." + METHOD + "." + RAW_BODY
* Toleransi selisih waktu timestamp maksimal 5 menit dari jam server untuk menangkal replay attack.
Contoh Pembuatan Signature (HMAC-SHA256):
php
<?php
// PHP 7.4+ HMAC-SHA256 Signature Generator
$apiKey = 'zyro_live_xxxxxxxxxxxxxxxxxxxxxxxx';
$apiSecret = 'sec_live_yyyyyyyyyyyyyyyyyyyyyyyy';

$timestamp = (string) round(microtime(true) * 1000);
$payload = [
    'ref_id' => 'INV-' . time(),
    'service_code' => 'ptero-pub-1gb',
    'data' => [ 'server_name' => 'Bot WhatsApp Store' ]
];
$rawBody = json_encode($payload);
$stringToSign = $timestamp . '.POST.' . $rawBody;
$signature = hash_hmac('sha256', $stringToSign, $apiSecret);

$ch = curl_init('https://zyrostore.id/api/v1/order');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $rawBody);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'Content-Type: application/json',
    'X-Zyro-Key: ' . $apiKey,
    'X-Zyro-Timestamp: ' . $timestamp,
    'X-Zyro-Signature: ' . $signature
]);
$res = curl_exec($ch);
curl_close($ch);
print_r(json_decode($res, true));

POST /api/v1/order
Signed POST

Pesan produk atau buat server Pterodactyl instan. Saldo deposit reseller akan dipotong secara atomik, dan kredensial server langsung diberikan.

REQUEST BODY PARAMETERS (JSON)
ParameterTipeStatusDeskripsi
ref_idStringWajibID referensi invoice unik dari sistem Anda (3-64 karakter). Anti-double order.
service_codeStringWajibKode layanan produk dari endpoint /services.
data.server_nameStringPANELNama server bot / project pembeli.
data.runtimeStringOpsionalEgg runtime engine: nodejs (default) atau python.
data.panel_usernameStringOpsionalCustom username pembeli (opsional).
data.panel_passwordStringOpsionalCustom password pembeli (opsional).
CONTOH REQUEST (DENGAN SIGNATURE)
curl
# cURL Terminal (Signed POST)
TIMESTAMP=$(date +%s%3N)
BODY='{"ref_id":"INV-10029","service_code":"ptero-pub-1gb","data":{"server_name":"Bot Store"}}'
SIGNATURE=$(echo -n "\${TIMESTAMP}.POST.\${BODY}" | openssl dgst -sha256 -hmac "YOUR_API_SECRET" | awk '{print $2}')

curl -X POST https://zyrostore.id/api/v1/order \
  -H "Content-Type: application/json" \
  -H "X-Zyro-Key: YOUR_API_KEY" \
  -H "X-Zyro-Timestamp: \${TIMESTAMP}" \
  -H "X-Zyro-Signature: \${SIGNATURE}" \
  -d "\${BODY}"

Signed POST

Cek rincian status pesanan, kredensial server, atau kode voucher berdasarkan ref_id sistem Anda atau trx_id dari SeikaOne.

REQUEST BODY PARAMETERS (JSON)
ParameterTipeStatusDeskripsi
ref_idStringKombinasiID referensi invoice unik dari sistem toko Anda.
trx_idStringKombinasiID transaksi internal SeikaOne (Contoh: ZYRO-H2H-...).
CONTOH REQUEST
curl
# cURL Terminal (Signed POST)
TIMESTAMP=$(date +%s%3N)
BODY='{"ref_id":"INV-10029"}'
SIGNATURE=$(echo -n "\${TIMESTAMP}.POST.\${BODY}" | openssl dgst -sha256 -hmac "YOUR_API_SECRET" | awk '{print $2}')

curl -X POST https://zyrostore.id/api/v1/status \
  -H "Content-Type: application/json" \
  -H "X-Zyro-Key: YOUR_API_KEY" \
  -H "X-Zyro-Timestamp: \${TIMESTAMP}" \
  -H "X-Zyro-Signature: \${SIGNATURE}" \
  -d "\${BODY}"
